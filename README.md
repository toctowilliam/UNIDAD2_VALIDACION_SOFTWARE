# Laboratorio de Pruebas Dinámicas - Unidad 2 (VVS)

Repositorio de la Actividad 2 de Verificación y Validación de Software. Incluye el módulo `src/compras.js`, las pruebas unitarias con Jest, la documentación del proceso y las evidencias de ejecución.

## Estructura del proyecto
- `src/`: código de `compras.js`.
- `tests/`: pruebas unitarias en `compras.test.js` (12 casos).
- `docs/`: plan de pruebas, matriz de casos y reporte final.
- `evidencias/`: salidas de consola de las pruebas iniciales, finales y de rendimiento.
- `scripts/`: script de prueba de rendimiento (`rendimiento.js`).

## Cómo ejecutarlo
1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Correr las pruebas unitarias:
   ```bash
   npm test
   ```
3. Correr la prueba de rendimiento:
   ```bash
   npm run rendimiento
   ```
